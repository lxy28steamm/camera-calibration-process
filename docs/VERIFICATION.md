## 3.0.6 复测判定与已有标定对比

新增固定于每次报告的判定依据和对比表：左右 RMS 显示历史值、本次值及参考差值；跨目预测与历史联合 RMS 分开列出；未记录的极线 P95 不填零。自定义阈值与依据备注写入 HTML / JSON 报告。数值差不用于自动诊断漂移，也不替代采样充分性要求；界面明确默认阈值不等同于标准认证。

本机 126 项 Python 测试及 3 项 JavaScript 测试通过。新增覆盖阈值等号边界、超限、缺失观测、无效历史数据、零历史 RMS、分辨率未确认、差值仅参考、不同算法不混比、依据备注校验、报告数据保存和 HTML 转义。

使用生成的 AprilGrid 图像验证实际网页复测：3 组不同姿态，左右 RMS 约 0.332 / 0.325 px，跨目 RMS 约 0.327 / 0.334 px，极线 P95 约 0.104 px。模拟标定历史左右 RMS 均为 0.1 px，网页正确显示 +0.232 / +0.225 px 参考差值且按本次阈值通过；联合 RMS 单列，极线历史值显示未提供。页面在采集期间与停止后均显示对比，浏览器未发现 JavaScript 错误；实时采集 / 预览仍约 30 FPS。此验证使用 min_views=3、min_cells=1 的测试设置，仅用于流程验证，未改变生产默认采样要求；本轮没有连接相机，不代表实机精度通过。
